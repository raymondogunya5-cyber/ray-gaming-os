# RAY GAMING OS – Infinix Hot 8 Edition

**RAY GAMING OS** ni Android Gaming Launcher iliyoundwa kwa ajili ya Infinix Hot 8.

## Features
- Gaming dashboard yenye muonekano wa PlayStation.
- Player 1 na Player 2 selection.
- Game library inayoonyesha apps zilizowekwa kwenye simu.
- Uwezo wa kufungua games moja kwa moja.
- Gaming artwork kwenye home screen.

## Requirements
- Android 6.0 au zaidi.
- Infinix Hot 8 (Android 9).

## Project Status
Version 1 – Development in progress.
